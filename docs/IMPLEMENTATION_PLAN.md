# Assessment delivery plan

Use case: independent designers and other creative freelancers preparing their books.

1. Establish a Python / React project and reproducible tooling.
2. Implement statement ingestion and an original, deterministic decision engine with adversarial tests.
3. Add persistent review, narrowly scoped learned rules, audit history, reconciled summaries and exports.
4. Build a responsive, accessible workspace with upload, explanations, review and category exploration.
5. Run integration and browser tests; document design, supported formats, limitations and actual AI usage.
6. Push `candidate-Wyrmstooth` to the fork and submit the specified pull request to upstream `main`.

Invariants: integer minor units, explicit sign/date conventions, no mixed-currency aggregation,
no silent malformed-row loss, no model decisions, no external transaction processing,
no real statement fixtures, and no fabricated usage measurements.
